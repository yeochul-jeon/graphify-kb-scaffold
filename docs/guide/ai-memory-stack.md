# AI Memory Stack Boundaries

This guide documents memory-layer responsibilities only. It does not require installing Mem0, Claude Code auto memory, or any other external memory service.

| Layer | Current path/tool | Stores | Do not store |
|---|---|---|---|
| Agent procedural rules | `AGENTS.md`, `CLAUDE.md`, `.claude/rules/` | How agents should work, test, and stay safe | Long documents, conversation transcripts |
| Project knowledge | `wiki/`, `docs/` | Architecture, decisions, concepts, command behavior | Raw private data |
| Source archive | `raw/` | Original inputs intended for compilation | Sensitive data outside ignored private zones |
| **Retrieval index** | `graphify-out/` | Derived knowledge graph over `raw`/`wiki`/`output`/`docs`. **`CLAUDE.md` makes `graphify query` the first action for any concept question**, so this is the de-facto primary search layer — not an optional export | Anything hand-edited; the whole tree is regenerated by `scripts/graphify-build.sh` |
| **Query trail** | `graphify-out/memory/` | Per-query records written by `graphify query` | Answers meant to be reviewed or promoted — those go to `output/` |
| **Answer staging** | `output/` | `/ask` answers and governance artifacts (lint reports, approval dossiers); the source pool `/review` promotes from | Anything already promoted to `wiki/` (would duplicate the SSoT) |
| Work memory | `.work-log/`, `log.md` | Session notes, dev-log, decisions | Permanent project facts without review |
| User/global memory | future Mem0 or equivalent | Stable user preferences and cross-project patterns | PR diffs, API docs, full chat logs |
| Claude project auto memory | `~/.claude/projects/<slug>/memory/` — **active**, outside this repo | Local project observations and debugging patterns | Secrets, source archives |
| Session observation capture | `claude-mem` plugin — **installed**, writes to its own store outside this repo | Cross-session observations, auto-injected context | Anything treated as authoritative — see caveat below |

> ⚠️ **`claude-mem` summaries are not a source of truth.** A recorded instance reversed a conclusion (an observation correctly read "all 4 source-omission findings were false positives" while the session summary rendered it as "confirmed real, not false positives"). The ledger (`wiki/_meta/suggested-investigations.md`, `wiki/_meta/weather.md`) is the single source; memory output is a pointer to re-check, never the verdict. Precedent: `.claude/reports/handoff/2026-07-28-001-compile-plan.md`.

> The last two rows were listed as `future` until 2026-08-16. Both are now installed and running; `Mem0` is the only row that remains prospective.
